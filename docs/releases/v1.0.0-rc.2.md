**Second release candidate for SteroidTracker 1.0.** Track TRT, HRT, peptides and bloodwork. Offline.

Install **SteroidTracker-v1.0.0-rc.2.apk** over 1.0.0-rc.1, 0.6.0 or 0.5.x; it updates in place and your plan, logs, journal and settings stay.

## Home screen widget
- Follows the wallpaper (Material You) colours on Android 12+, like the launcher's own widgets; older Android keeps the app's colour scheme.
- Uses the system widget corner radius and background.
- Status marks match the app: taken is a filled check, due an accent ring, missed a red ring, skipped a muted ring. The empty rings no longer show as grey circles.
- Taken and skipped doses stay in the list in place, so a row doesn't jump after a one-tap check.
- Resizes from one row (next dose) through a short card to the full list.
- The widget picker shows a preview.
